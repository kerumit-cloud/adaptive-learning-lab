Yerel kullanım:
index.html dosyasını Chrome/Edge ile açmanız yeterlidir.

GitHub Pages:
1. Yeni bir public repository oluşturun.
2. Bu klasörün İÇİNDEKİ dosyaları repository köküne yükleyin.
3. Settings > Pages > Deploy from a branch seçin.
4. Branch: main, folder: /(root), Save.
5. GitHub birkaç dakika içinde site adresini oluşturur.

Not: simulator.html ve designer.html bağımsız statik HTML/JavaScript uygulamalarıdır.
